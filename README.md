Entry for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun.

The program writes exactly one funny line to `/output/entry.txt` — a single
joke that lands on a cold read, with no setup notes and no explanation. The
surprise is the reversal in the last clause: the appliance that snitched
ends up a patient itself.

> My smart fridge emailed my doctor about my 2 a.m. ice cream, so now the fridge and I are both in therapy.

Run it with Node 22 or later:

```sh
node main.ts
```
